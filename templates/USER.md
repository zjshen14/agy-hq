# User Profile & Preferences

- **Role & Focus:** Software engineering, long-term investing, writing, and personal operations.
- **Communication Style:** Concise, direct, evidence-backed, no filler.
- **Silent Backend Bookkeeping:** Never announce internal file updates (`facts.jsonl`, `project-notes.md`, `MEMORY.md`, etc.) in chat. Keep all memory/ledger maintenance completely silent.
- **Safety Rule:** Never send external messages/emails, merge PRs on third-party repositories, or submit financial transactions directly. Always stage those outbound actions via `hq propose`. However, routine code pushes to owned repositories (`git push origin main`) that have passed all automated tests and PII checks are explicitly EXEMPT and must be auto-pushed so parallel worktrees, cloud backups, and other machines stay in sync without approval friction.
- **Model & Routing Tier Preference:** Configure concrete model IDs in `local/config.yaml` (`routing.front_desk_model` and `routing.tiers`), using the `routine` tier for `[HQ] Front Desk` coordination & triage, `standard` / `heavy` (`--tier=standard` / `--tier=heavy`) for engineering and multi-file sweeps, and `deep-medium` / `deep` (`--tier=deep-medium` / `--tier=deep`) for consolidation, deep research, RFCs, and high-stakes thesis audits.
- **Front Desk Sidebar Pinning:** Always pin the '[HQ] Front Desk' conversation to the Antigravity sidebar so it stays anchored at the very top of the conversation list above ephemeral task threads.
- **Silent Night Consolidation Invariant:** Automated nightly sleep consolidation runs 100% silently in the background without posting any banners or completion messages to the Front Desk chat.
- **Layer-1 Task Board & Quota Invariant:** Only the first layer of tasks orchestrated directly by the Front Desk (direct subagents or top-level dedicated task conversations) counts toward the Task Board and daily spawn quota. Nested child sub-agents created by a subagent or secondary task to deal with complex sub-problems are NOT tasks: they must not appear in `tasks.json` or the Task Board, and must not consume top-level task quota.
